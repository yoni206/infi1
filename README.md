# אינפי 1 — אוניברסיטת בר־אילן, סמסטר א' תשפ"ז (2026–27)

- מרצה: [יוני זוהר](https://u.cs.biu.ac.il/~zoharyo1/)
- מתרגל: [צביקה ברגר](https://bergerzvika.github.io/Advanced-Programming/home.html)
- [עמוד הקורס במערכת השעות של האוניברסיטה](https://courses.biu.ac.il/CourseDetails.aspx?lid=822310)

## מטרות

הלומדים והלומדות:

1. יבינו את השפה המתמטית הפורמאלית וידעו להשתמש בה.
2. יסגלו הרגלים של חשיבה מתמטית מופשטת ומדוייקת.
3. יגדירו ויכירו את המונחים המרכזיים והבסיסיים של החשבון הדיפרנציאלי והאינטגרלי.
4. יפתרו תרגילים ויוכיחו משפטים באופן עצמאי.

## ציון

- בחינה: 80%
- בוחן: 10%
- תרגילי בית: 10%
  - תרגיל בית ניתן מדי שבוע.
  - ציון התרגילים הוא ממוצע 10 התרגילים הטובים ביותר.
  - תרגיל שלא הוגש ציונו 0.

ציון עובר הוא 60. כדי לעבור את הקורס יש לעבור כל אחד מרכיבי הציון בנפרד, למעט הבוחן המהווה מגן.

בנוסף:

מדי שבוע יינתן בוחן מקוון קצרצר. הבוחן אינו נספר בציון (0%), אך מומלץ מאוד לפתור אותו.
